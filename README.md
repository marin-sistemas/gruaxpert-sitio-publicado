# gruaxpert.com.mx · sitio publicado

Este repositorio contiene **sólo el sitio ya compilado** de GrúaXpert: lo mismo que cualquier visitante descarga de gruaxpert.com.mx. El código fuente, la base de datos y los documentos viven en el repositorio privado de trabajo.

cPanel (Git Version Control) jala este repositorio y `.cpanel.yml` copia los archivos a la carpeta del dominio. No se edita a mano: se regenera con `site/build.py` del repositorio de trabajo.
